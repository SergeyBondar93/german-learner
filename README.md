# Wort für Wort

Автономный мобильный веб-тренажёр немецкой грамматики A2–B2 с объяснениями на русском и практикой перевода на немецкий. Репозиторий содержит только статическую веб-версию и инструменты для её сборки, тестирования и публикации.

## Открыть приложение

Откройте сайт по ссылке: [sergeybondar93.github.io/german-learner](https://sergeybondar93.github.io/german-learner/). Страница адаптирована для телефона и компьютера.

Также можно открыть файл `index.html` в современном браузере или передать его на телефон.

## GitHub Pages

Публикация настроена через GitHub Actions: при каждом push в `main` workflow устанавливает зависимости, пересобирает веб-страницу и публикует `index.html`.

## Обновить веб-страницу

После изменения учебных материалов выполните в проекте:

```sh
npm ci
npm run build:html
```

Команда пересоберёт `index.html`, встроив в него все 25 тем и по 50 заранее составленных упражнений на каждую тему, а также отдельную тему с 500 упражнениями на личные местоимения. Синтетические варианты не используются: для каждого раунда случайно выбираются 15 заданий из готового набора.

## Учебный материал

В приложении есть уровни A2 (8 тем), B1 (9 тем) и B2 (8 тем). Темы охватывают формы прошедшего времени, падежи и предлоги, окончания прилагательных, степени сравнения, придаточные предложения, управление глаголов, косвенную речь, пассив, Genitiv и причастные определения. Следом за B2 доступна отдельная тема «Местоимения»: 150 упражнений на ich, du, er, sie, es и 350 на wir, ihr, sie и вежливое Sie. В наборе отрабатываются Nominativ, Akkusativ и Dativ. При каждом открытии темы случайно выбирается 15 заданий для раунда. В упражнении нужно собрать перевод из перемешанных кликабельных слов. Количество отвлекающих тегов — 30% от ответа с округлением вниз, но не меньше двух. Проверка допускает некоторые грамматически эквивалентные формы артикля с тем же падежным окончанием и перестановку дополнений Dativ/Akkusativ у глаголов с двумя дополнениями; для других слов и порядков сохраняется строгая проверка. Прогресс хранится в localStorage: рядом с темой показано число уникальных предложений, которые проверялись хотя бы один раз, а на главном экране его можно очистить. Также можно нажать «Сказать предложение»: если браузер поддерживает распознавание речи, произнесённые по-немецки слова автоматически выберутся в ответе. Приложение использует до пяти вариантов распознавания и осторожно сопоставляет слова, похожие по написанию на слова правильного ответа; неоднозначные совпадения оставляет для ручной правки. Точность распознавания зависит от браузера и микрофона; приложение не оценивает произношение. Рядом есть кнопка воспроизведения правильного немецкого ответа; она становится доступна после первой проверки ответа. На GitHub Pages страница открывается по HTTPS, что позволяет браузеру запрашивать доступ к микрофону. Поддержка распознавания зависит от браузера и разрешения на микрофон; некоторым браузерам также нужен интернет, а аудио может обрабатываться их онлайн-службой. При недоступности распознавания слова можно выбрать вручную. При открытии HTML-файла напрямую доступ к микрофону может быть ограничен браузером.

### Как сверялась программа

Список пробелов составлен по общему охвату уровней и коммуникативной направленности серий для изучающих немецкий: [Schritte plus Neu (A1–B1)](https://www.hueber.de/reihe/schritte-plus-neu), [Sicher! (B1+–C1)](https://www.hueber.de/reihe/sicher), [Netzwerk (Klett)](https://www.klett-sprachen.de/netzwerk/r-1/187) и [Aspekte neu (Klett, начиная с B1)](https://www.klett-sprachen.de/aspekte-neu/r-1/15). Это сопоставление тематического охвата по уровням, а не копирование или дословная сверка заданий по страницам учебников; все упражнения в приложении составлены самостоятельно. Добавлены недостающие крупные блоки: окончания прилагательных и сравнение (A2), косвенные вопросы, временные придаточные и управление глаголов (B1), Genitiv и причастные определения (B2).

## Проверки

```sh
npm run build:html
npm test
npm run typecheck
npm run lint
```

Тесты проверяют полноту учебных данных, количество, уникальность и длину предложений в тематических пулах, распределение всех 500 упражнений на местоимения и правила выбора и проверки слов. Команда сборки также проверяет наличие 50 вариантов в каждой обычной теме, уникальность заданий и формат каждого набора слов перед созданием HTML-файла.
