# Wort für Wort

Офлайн-тренажёр немецкой грамматики A2–B2 с объяснениями на русском и упражнениями на немецкий. Основная версия приложения — автономная мобильная веб-страница в файле `index.html`.

## Открыть на телефоне

Скопируйте `index.html` на телефон и откройте его в браузере или файловом менеджере. Для упражнений и учебных материалов не нужны сервер, интернет или установка приложения. Ссылки на дополнительные объяснения откроются при наличии интернета.

Файл удобно передать на телефон через USB, облачное хранилище или мессенджер. Если браузер на телефоне не открывает HTML прямо из файлов, поместите файл на любой статический хостинг и откройте ссылку — приложение также будет работать офлайн после загрузки страницы.

## GitHub Pages

Публикация настроена через GitHub Actions: при каждом push в `main` workflow устанавливает зависимости, пересобирает автономную страницу и публикует `index.html`. Для первого запуска включите Pages с источником `GitHub Actions` в настройках репозитория.

## Обновить автономную страницу

После изменения учебных материалов выполните в проекте:

```sh
npm install
npm run build:html
```

Команда пересоберёт `index.html`, встроив в него все 18 тем и по 50 заранее составленных упражнений на каждую тему, а также отдельную тему с 500 упражнениями на личные местоимения. Синтетические варианты не используются: для каждого раунда случайно выбираются 15 заданий из готового набора. Готовый файл можно сразу скопировать на телефон.

## Учебный материал

В приложении есть уровни A2, B1 и B2; каждый содержит шесть тем. Следом за B2 доступна отдельная тема «Местоимения»: 150 упражнений на ich, du, er, sie, es и 350 на wir, ihr, sie и вежливое Sie. В наборе отрабатываются Nominativ, Akkusativ и Dativ. При каждом открытии темы случайно выбирается 15 заданий для раунда. В упражнении нужно собрать перевод из перемешанных кликабельных слов. Количество отвлекающих тегов — 30% от ответа с округлением вниз, но не меньше двух. Также можно нажать «Сказать предложение»: если браузер поддерживает распознавание речи, произнесённые по-немецки слова автоматически выберутся в ответе. На GitHub Pages страница открывается по HTTPS, что позволяет браузеру запрашивать доступ к микрофону. Поддержка распознавания зависит от браузера и разрешения на микрофон; некоторым браузерам также нужен интернет, а аудио может обрабатываться их онлайн-службой. При недоступности распознавания слова можно выбрать вручную. При открытии HTML-файла напрямую доступ к микрофону может быть ограничен браузером.

## Проверки

```sh
npm run build:html
npm test
npm run typecheck
```

Тесты проверяют полноту учебных данных, количество, уникальность и длину предложений в тематических пулах, распределение всех 500 упражнений на местоимения и правила выбора и проверки слов. Команда сборки также проверяет наличие 50 вариантов в каждой обычной теме, уникальность заданий и формат каждого набора слов перед созданием автономного HTML-файла.
