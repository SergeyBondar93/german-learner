# Wort für Wort

Мобильный тренажёр немецкой грамматики на React Native и Expo. Объяснения и задания даны на русском языке; примеры и ответы — на немецком.

## Запуск

```sh
npm install
npm run start
```

Для запуска на устройстве или эмуляторе:

```sh
npm run android
npm run ios
npm run web
```

Для iOS-сборки нужен macOS и Xcode. Веб-версия запускается в браузере. Можно также открыть мобильное приложение в Expo Go, отсканировав QR-код из запущенного Expo Dev Server.

## Учебный материал

В приложении есть три уровня: A2, B1 и B2. Каждый уровень содержит шесть тем; в каждой теме — объяснение на русском, примеры, практическая подсказка и 15 упражнений. В упражнении нужно собрать перевод из кликабельных слов: в наборе ровно вдвое больше слов, чем в ответе, а отвлекающие варианты связаны с грамматической темой.

## Проверки

```sh
npm test
npm run typecheck
npm run lint
npx expo-doctor
```

Тесты проверяют полноту и формат учебных данных, правила выбора и проверки слов, а также основные сценарии интерфейса.
