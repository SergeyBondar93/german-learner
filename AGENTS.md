# Инструкции для агентов

## Продукт

**Wort für Wort** — русскоязычный мобильный веб-тренажёр немецкого уровня A2–B2. Он помогает изучать грамматику в контексте: ученик читает краткое объяснение, примеры и подсказку на русском, затем собирает перевод бытового предложения из кликабельных немецких слов. Интерфейс рассчитан на телефон, работает и на компьютере. Приложение — статический сайт без серверного API и без React/React Native; основная версия распространяется через GitHub Pages и также может открываться как автономный `index.html`. Исключение из автономной работы — голосовые функции: их поддержка зависит от браузера, разрешений и доступности браузерных речевых служб.

## Что доступно пользователю

- Главный экран с уровнями A2, B1, B2 и отдельной темой «Местоимения».
- В каждом уроке: описание грамматики, немецкие примеры, русскоязычная подсказка и необязательная ссылка на внешний справочный материал.
- В каждом раунде темы случайно выбираются 15 заданий без повторов внутри раунда. Открытие темы начинает новый раунд.
- Задание показывает русское предложение и перемешанный набор слов. Нажатие на тег добавляет его в ответ, нажатие на выбранное слово удаляет его. После проверки показываются результат и правильный вариант; затем можно перейти дальше.
- Кнопки «Сказать предложение» и «Воспроизвести» находятся в нижней фиксированной панели над основной кнопкой. Панель должна оставаться доступной при прокрутке и учитывать safe area мобильного устройства.
- Распознавание речи по-немецки предлагает до пяти вариантов распознавания, сопоставляет слова с набором ответа и может подобрать однозначно похожее по написанию слово. Оставшиеся слова ученик исправляет вручную. Это не оценка произношения; распознавание не гарантируется браузером.
- Воспроизведение правильного ответа использует Web Speech Synthesis, немецкий голос `de-DE` при наличии и доступно после первой попытки ответа.
- Прогресс хранится в `localStorage`: уникальное задание засчитывается при проверке, независимо от правильности. Счётчик отображается у темы; на главном экране доступна очистка прогресса.

## Учебный материал и контракты данных

- 25 основных тем: A2 — 8, B1 — 9, B2 — 8. Каждая содержит 50 русско-немецких заданий; в раунд попадают 15.
- Дополнительная тема «Местоимения» содержит 500 заданий: 150 для единственного и 350 для множественного числа; отрабатываются Nominativ, Akkusativ и Dativ, включая `Sie`.
- Все 50 заданий каждой из 25 основных тем — вручную составленные авторские примеры для повседневных ситуаций: 15 базовых плюс 35 записей в пуле дополнений. Сохраняй соответствие между переводом, целевой грамматикой и немецкой фразой; не заменяй эти наборы автоматически генерируемыми вариантами. Пул местоимений — отдельное исключение: его 500 уникальных фраз строятся в `src/pronounExercises.ts` из проверяемых шаблонов и контекстов.
- Каждое предложение-задание содержит 4–12 слов. В наборе ответа должны присутствовать все слова правильного варианта, а количество отвлекающих слов — `max(2, floor(0.3 × число слов ответа))`. Отвлекающие варианты должны быть правдоподобными грамматическими/лексическими ошибками, а не случайными словами.
- У каждой темы стабильный уникальный `id`, уровень (`A2`, `B1`, `B2`), непустые название/описание/объяснение/подсказка, хотя бы один пример и ровно 15 базовых упражнений. Не меняй идентификаторы без необходимости: от них зависят маршрутизация и ключи прогресса.
- Актуальный перечень тем смотри в `src/content.ts`; распределение местоимений — в `src/pronounExercises.ts`. Проверки в `src/contentValidation.ts` и `__tests__/content.test.ts` фиксируют формат и объёмы.

## Проверка ответов и важные ограничения

- `src/trainer.ts` — источник истины для токенизации, подготовки тегов и сравнения ответов. Проверка нечувствительна к регистру и конечной пунктуации, но в остальном сохраняет строгий порядок слов.
- Уже предусмотрены ограниченные грамматические альтернативы: некоторые пары артиклей с тем же падежным окончанием; перестановка Dativ/Akkusativ для поддерживаемых глаголов с двумя дополнениями; опускание артикля перед перечисленными неисчисляемыми существительными и существительными во множественном числе. Не расширяй допуски так, чтобы принимались грамматически неверные ответы.
- `src/speechMatching.ts` отвечает только за сопоставление распознанных слов и вариантов транскрипции. Не выдавай результат распознавания за оценку правильности произношения.
- Сохраняй текущую мобильную компоновку, доступность кнопок/состояний и работу при отсутствии Web Speech API. Ошибки сохранения или повреждённый прогресс не превращай в незаметный успешный результат.

## Архитектура и источники истины

- `src/content.ts` — 15 базовых упражнений, метаданные, объяснения и примеры основных тем.
- `src/authoredExercisePools.ts` — 35 вручную составленных дополнительных упражнений для каждой основной темы.
- `src/pronounExercises.ts` — данные и проверки 500 упражнений по местоимениям.
- `src/trainer.ts` — сборка тегов, нормализация и проверка ответов.
- `src/speechMatching.ts` — подбор слов по распознанной речи.
- `src/progress.ts` — работа с локальным прогрессом (ключ `wort-fuer-wort-progress-v1`).
- `src/types.ts` — общие типы; `src/contentValidation.ts` — валидация содержимого.
- `scripts/build-standalone.mjs` — сборка всех данных и логики в самостоятельную HTML-страницу. Он проверяет размер и уникальность пулов и генерирует случайные теги/раунды.
- `index.html` — **сгенерированный артефакт**, публикуемый на Pages. Никогда не редактируй его вручную: меняй исходники и запускай сборку.
- `__tests__/` — Jest unit-тесты для контента, тренажёра, прогресса и речи. Проект не содержит нативного приложения.
- `.github/workflows/pages.yml` — при push в `main` устанавливает зависимости, пересобирает HTML и деплоит его в GitHub Pages. Не заменяй workflow мобильной сборкой.

## Рабочий процесс

1. Перед изменениями изучи соответствующий исходник и тесты; сохраняй существующие данные и незатронутое состояние рабочей копии.
2. При изменении поведения, контента или стилей обновляй исходник и связанные тесты. Для изменения контента/интерфейса синхронизируй `index.html` командой сборки.
3. Проверь результат в самом HTML, а не только в TypeScript-модуле: критичные взаимодействия (проверка/переход, порядок кнопок, адаптивность) проверяй в браузере, если это возможно.
4. Для изменений сайта запусти:

   ```sh
   npm run build:html
   npm test
   npm run typecheck
   npm run lint
   ```

5. Не добавляй зависимости без необходимости и не вводи серверную часть, сторонний API, framework или Expo/React Native без отдельного запроса.

## Команды и публикация

- `npm ci` — установить зависимости из lock-файла.
- `npm run build:html` — собрать `index.html`.
- `npm test` — выполнить Jest-тесты.
- `npm run typecheck` — проверить TypeScript без генерации файлов.
- `npm run lint` — запустить ESLint.
